# Global-market
Global Market is a modern e-commerce website built from scratch using HTML, CSS, and vanilla JavaScript.

The project focuses on building a complete shopping experience while practicing real-world front-end development concepts such as product rendering, dynamic cart functionality, search, filtering, quick product views, and checkout interactions.

Features
🛒 Dynamic shopping cart with localStorage
🔍 Product search and search results overlay
👀 Quick-view product modal
🏷️ Product categories and collections
💰 Dynamic product pricing and currency formatting
📦 Cart and checkout pages
➕ Add-to-cart functionality
🗑️ Remove products from cart
📱 Responsive and modern UI
⚡ Dynamic product rendering with JavaScript ES Modules
💾 Persistent cart data using browser localStorage
Technologies
HTML5
CSS3
JavaScript (ES6+)
ES Modules
LocalStorage
Git & GitHub
Purpose

This project was built as a practical front-end development project to strengthen my JavaScript skills and understand how different parts of an e-commerce application communicate with each other — from product data and UI rendering to cart management and checkout functionality.
